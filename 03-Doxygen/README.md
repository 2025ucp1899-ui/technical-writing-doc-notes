

\# Doxygen – Source Code Documentation



\## Introduction

Doxygen is a documentation generation tool used to create documentation from source code.



\## Objectives

\- Understand Doxygen.

\- Learn documentation comments.

\- Generate HTML and PDF documentation.

\- Document classes, functions and variables.



\## Topics Covered

\- Introduction to Doxygen

\- Documentation blocks

\- Commands and tags

\- Configuration files

\- HTML documentation generation

\- Code documentation



\## Practical Work

Create documentation for a sample C++ program using Doxygen.



\## Tools Required

\- Doxygen

\- C++

\- Graphviz

\- VS Code



\## Learning Outcome

Understand how to generate structured software documentation using Doxygen.
