\# GitHub Notes



\## What is GitHub?

GitHub is an online platform that hosts Git repositories.



\## Important Concepts



\- \*\*Repository:\*\* A location where project files are stored.

\- \*\*Remote Repository:\*\* An online version of a Git repository.

\- \*\*Fork:\*\* Creating your own copy of another user's repository.

\- \*\*Pull Request:\*\* A request to merge proposed changes.

\- \*\*Issues:\*\* Used to report bugs or track tasks.

\- \*\*README:\*\* A file explaining the project.



\## Git vs GitHub



| Git | GitHub |

|---|---|

| Version control system | Online hosting platform |

| Works locally | Works online |

| Tracks file changes | Supports collaboration |
