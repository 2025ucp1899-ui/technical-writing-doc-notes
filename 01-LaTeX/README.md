# LaTeX – Scientific Document Preparation

## Introduction

LaTeX is a document preparation system widely used for creating scientific papers, research articles, academic reports, books, and technical documentation.

Unlike traditional word processors, LaTeX uses markup commands to control document structure and formatting.

## Objectives

- Understand the fundamentals of LaTeX.
- Learn basic LaTeX syntax and commands.
- Create structured technical documents.
- Format mathematical equations.
- Insert tables, figures, and lists.
- Generate PDF documents.

## Topics Covered

1. Introduction to LaTeX
2. Document classes and environments
3. Packages and preamble
4. Text formatting
5. Sections and subsections
6. Mathematical equations
7. Tables and figures
8. Lists and references
9. Document compilation
