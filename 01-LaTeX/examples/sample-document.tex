\section{Introduction}

LaTeX is a document preparation system widely used
for scientific papers, academic reports, and technical
documentation.

It provides professional formatting and supports
complex mathematical expressions.

\section{Features of LaTeX}

Some important features of LaTeX are:

\begin{itemize}
    \item Professional document formatting
    \item Mathematical equation support
    \item Automatic numbering
    \item Bibliography management
    \item Cross-referencing
\end{itemize}

\section{Mathematical Equations}

The following is an example of the Pythagorean theorem:

\[
a^2+b^2=c^2
\]

An example of a quadratic equation is:

\[
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
\]

\section{Text Formatting}

LaTeX supports different text styles:

\begin{itemize}
    \item \textbf{Bold text}
    \item \textit{Italic text}
    \item \underline{Underlined text}
\end{itemize}

\section{Conclusion}

LaTeX is a powerful tool for technical writing.
It helps create well-structured documents with
professional formatting, equations, tables, and references.
