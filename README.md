# 📚 Technical Writing Notes

### Technical Documentation, Scientific Typesetting & Version Control

> Learn. Document. Collaborate. Version.

A structured repository documenting the concepts, tools, and practical skills acquired through the Technical Writing course.

## About

This repository explores six essential tools used in technical documentation:

1. LaTeX – Scientific document preparation
2. Beamer – Academic presentations
3. Doxygen – Source code documentation
4. Google Docs – Collaborative documentation
5. Git – Distributed version control
6. GitHub – Repository management and collaboration

## Repository Objectives

- Understand professional technical writing.
- Create structured technical documents.
- Design academic presentations.
- Generate source code documentation.
- Learn collaborative editing.
- Understand version control and GitHub workflows.
