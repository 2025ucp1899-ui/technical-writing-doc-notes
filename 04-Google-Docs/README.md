

\# Google Docs – Online Document Creation



\## Introduction

Google Docs is a web-based word processing application used to create, edit and share documents.



\## Objectives

\- Understand Google Docs.

\- Learn document formatting.

\- Insert tables, images and links.

\- Collaborate with others.



\## Topics Covered

\- Creating documents

\- Text formatting

\- Page setup

\- Headers and footers

\- Tables and images

\- Comments and suggestions

\- Sharing and collaboration



\## Practical Work

Create a formatted technical report using Google Docs.



\## Tools Required

\- Google Docs

\- Google Drive

\- Web browser



\## Learning Outcome

Learn to create and collaborate on professional documents using Google Docs.
