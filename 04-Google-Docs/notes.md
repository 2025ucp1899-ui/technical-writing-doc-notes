

\# Google Docs Notes



\## 1. Introduction

Google Docs is an online word processor provided by Google.



\## 2. Main Features

\- Real-time collaboration

\- Automatic saving

\- Cloud storage

\- Document sharing

\- Version history



\## 3. Formatting

Google Docs allows users to change:

\- Font style and size

\- Text colour

\- Alignment

\- Line spacing

\- Paragraph spacing



\## 4. Inserting Elements

Users can insert:

\- Tables

\- Images

\- Charts

\- Hyperlinks

\- Page numbers



\## 5. Collaboration

Multiple users can work on the same document.



\## 6. Sharing Options

\- Viewer

\- Commenter

\- Editor



\## 7. Advantages

\- Easy accessibility

\- Automatic saving

\- Collaboration

\- Easy sharing



\## Conclusion

Google Docs provides a convenient platform for creating and editing documents online.
